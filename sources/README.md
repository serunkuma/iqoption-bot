# Sources

Status: Historical

> Raw input documents that informed this project's documentation. Frozen by design — do not edit.

---

## What Lives Here

| File | What it is |
|------|------------|
| `AMT_ML_DISCUSSION.md` | Raw Auction Market Theory / ML discussion pasted by the project owner from another AI conversation |
| `PROJECT_CONTEXT.md` | Extracted description of the repository as it existed at documentation time |
| `INTERVIEW_TRANSCRIPT.md` | Structured record of the decisions and open questions from the documentation conversation |

Files are named descriptively. There is no numbering scheme — these are inputs, not a curriculum.

---

## Rules

1. **Do not edit anything in here.** These are frozen inputs. To update project knowledge, edit the relevant `docs/concepts/`, `docs/data/`, or `docs/system/` file instead.
2. **Commit everything to git.** Traceability matters more than repo size for `.md` files.
3. **Status: Historical, always.** Every file here is historical the moment it is captured. Do not relabel.
4. **No status label is required inside individual source files.** This README declares the folder Historical; individual inputs can keep their original structure.
5. **If a source is superseded,** leave it here untouched and update the relevant `docs/` file with what changed and when.

---

## Why This Folder Exists

Without preserved inputs, six months from now no one can answer "why did we make this decision?" The `docs/` tree captures current state; `sources/` captures the inputs that produced it.
